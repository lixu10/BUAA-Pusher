# PUAA

面向北航学生的多用户日程与提醒系统。Python 单体服务、SQLite 持久化，不包含演示数据。

当前调试范围（2026-10-13）：开放 **SPOC 作业、课程提醒（教务课表）、JUDGE 作业、独立课程签到检查（iClass）、只读博雅课程、自定义日程**。其余业务仍为 `Coming Soon`，不能启用、同步或发送提醒，代码与数据保留。签到和博雅默认停用，旧签到规则保留为“待配置”，需重新设置检查点后使用。

今日／日历可新建自定义日程，支持起止时间、全天、地点、折叠备注及后续编辑／删除。新建时勾选“同时设置提醒”，设置1–10个开始前／开始时／结束前／结束时的提醒，提前量精确到天、小时、分钟，可选择站内通知或本人已启用的通知渠道及安静时段策略。只生成该条日程的提醒规则和任务，修改时间会重排，删除日程或移除提醒会一并清理；规则也可在提醒页面停用、启用和进入日程编辑。个人日程不受学期过滤限制，不调用学校同步接口。待办是否显示个人日程可在账户设置中同时勾选“自定义日程”和“个人”来源，默认保留原有筛选。详见 [自定义日程设计](docs/CUSTOM_EVENTS_DESIGN.md)。

课程提醒只使用 BYXT 教务课表，展示课程名、起止时间、教师和教室，可配置上课前或结束前多少分钟及通知方式。签到是独立连接与规则：1–10 个分钟级检查点，范围为开始前10分钟至结束；只查询、不执行签到。已同步为已签到则不再查询，取消该课次当前规则后续检查；失败、未知或无法匹配不误报未签到。多渠道和发送重试共用一次检查结果。日历只附签到状态、不重复列课，教务独有课程正常显示；未匹配 iClass 记录在连接详情显示，可按规则排除课程。详见 [签到设计](docs/ATTENDANCE_DESIGN.md)。

连接页支持单项手动同步和实时进度，来源互不阻塞。待办支持提交状态、来源、作业类型和过期筛选，日期包含年份；今日与日历可切换已完成事项。提醒规则以“连接 → 规则类型”选择：课程提醒/变更（含新增），SPOC 截止/新作业/新评分，JUDGE 截止/新作业。截止提醒支持多个“天 + 小时 + 分钟”提前量，总量至少 1 分钟，可分别筛选提交状态。首次完整同步仅建立变更基线，不发送历史变化。

“账户与安全 → 待办显示”按事项类型、来源保存每个用户的偏好，默认只显示作业，不显示教务课程或博雅课程；可以勾选需要的类型和来源，全部取消则不显示待办。它只控制待办列表，不删除数据、不停用课程提醒、不改变今日和日历。待办右上角可直接打开设置。

博雅页面分“已报名”和“课程列表”：已报名课程按真实起止时间进入今日和日历，不额外生成签到/签退日程；目录只用于查看及提醒，不塞入个人日程。目录支持分类、校区、签到方式、报名状态和名称筛选，详情含报名/退选时间、人数与余量、教师、地点、适用人群、简介、签到/签退窗口和已知个人考核/作业信息，长文本默认折叠。已报名默认每30分钟同步，目录默认每5分钟同步，可分别设置或改成手动。

博雅有七种规则：上课提醒、已报名课程变更、新课程、报名即将开放、报名开放、名额回流、报名即将截止。目录规则按分类、校区、签到方式、关键词、排除关键词或指定课程筛选；开放前/截止前支持1–10个分钟级提前量。新课程首次同步静默；名额回流按最低余量阈值跨越检测，可设置通知间隔。抢课规则新建默认照常发送，不被安静时段延后，用户可修改。发送前同步已报名状态，再逐门只读复核目标课程详情；已报名、满员、改期、结束或状态不明时不误发。系统不自动报名、退选、签到或签退，详见 [博雅设计](docs/BOYA_DESIGN.md)。

学校事项通知使用详细的分行内容：本地年月日与时间、课程与教师、地点、提交进度、已知得分/评语、变化前后对比、报名时间/余量及学校入口等。正文提供摘要，完整内容仍在详情；站内正文默认折叠。短信网关使用精简后的同一模板，不发送长正文或长评语，实际长度限制由用户所接网关决定。凭据、Cookie、token、学号和未确认状态不加入业务消息。

每次实际发送学校事项通知前，会额外同步对应连接，并重新判断完成状态、日期、忽略及规则条件；已有手动/定时同步正在进行时直接等待其结果。同轮同用户同连接的多项通知、多个渠道共用最多30秒的新结果，超过后重新同步。作业已提交、课程改期或通知变化被撤销后，旧通知取消或重排。同步失败/部分成功时暂不发送缓存通知，按1/5/15分钟重试；安静时段延后、渠道发送重试也会重新复核，截止提醒不越过截止时间。连接设为“手动”仍执行通知前同步，关闭连接则停止相应提醒。签到采用检查点只读复核，已签到直接取消后续检查；连接故障提示和渠道测试消息直接发送。

所有学校连接均可单独选择“直连（校内）”或“学校 WebVPN”，选择按用户、按连接保存；Coming Soon 连接可预设模式但不能启用。校外 JUDGE 使用学校 `d.buaa.edu.cn`，不接入 UBAA 服务。WebVPN 有独立会话与验证码；加密保存密码后可自动登录，否则点击对应行“登录”，会话不落盘。签到支持连接页设置自动同步间隔，也支持手动同步；与规则检查点分别配置。只在同步和检查点查询，页面及日历读取缓存。

2026-10-21 已兼容学校用户中心返回 HTTP SSO 跳转的认证流程：直连／WebVPN 均显式完成 HTTPS 票据交换，保留原始 service 编码，最多10次跳转；不关闭 TLS 校验，也不向其他地址转发密码。用户中心会话建立失败与真正的密码错误分开提示，前者短暂冷却后允许恢复。JUDGE 返回无法确认的空页面时会报错并保留旧数据，不当作课程或作业被全部删除。更新服务器代码并重新构建容器后生效；部署环境的原有内存认证阻断随进程重启清除。

“账户与安全”中的学期过滤默认开启：2 月 1 日至 9 月 1 日、8 月 1 日至次年 3 月 1 日（结束日期不含当天），重叠期间取有效窗口并集。可以自定义日期或关闭过滤，统一作用于今日、日历、待办和提醒；旧数据不删除，范围外不提醒，JUDGE 已知旧作业不重复读取详情。

今日仅看当天待处理与 7 天内截止事项；日历只提供日/周/月时间安排；待办管理提交、完成和忽略状态。单项忽略不会改变学校的提交记录，同步后保持忽略，不展示在今日/日历且不提醒；可在待办“已忽略”中取消忽略。

电脑周日程默认显示08:00–22:00，00:00–08:00和22:00–24:00没有本周课程时折叠，有真实课程则自动展开，用户也可手动展开完整0–24点。紧凑模式根据可见高度压缩小时行，可切舒适模式；日期与截止/全天栏固定，时间轴独立滚动。作业按截止时间放在顶部，不虚构持续时长；跨日课程拆分、重叠并排，点击查看详情。手机周视图用七天日期/数量概览和选中当天的全宽日程，显示课程名、实际时间、教师、地点，不把七列宽表撑到页面外。

手机底部是带图标与文字的今日/日历/待办/博雅/更多五个入口，更多菜单内有提醒、连接、渠道和账户。手机去掉重复全局标题，今日日期和同步按钮同排，各页面使用自身标题/操作；日历仅保留紧凑日期切换条。支持安全区，详情和所有必要设置仍可访问。

博雅签到方式按学校公开前端确认为“常规签到（1）／自主签到（2）”，列表、规则筛选与通知使用同一语义，签到/签退窗口另列。目录默认隐藏已开课/结束、报名已截止记录，“显示已过期”可以查看历史；已报名且尚未上完的课程继续进入日程。

今日、待办和日历共用只读详情窗口。基本时间、教师、教室、提交状态及已知得分直接显示；作业正文、教师评语、JUDGE 题目明细和课程信息默认折叠，可分别展开。长正文保留换行、独立滚动，不执行学校 HTML 或自动加载外部资源。新增正文和题目字段随正常同步获取，不额外逐题请求；未返回的字段不虚构。短时课程卡片优先保留课程名与时间，次要信息在详情查看。

## 本地一键启动

Windows：

```powershell
.\start.ps1
```

macOS / Linux：

```bash
chmod +x start.sh
./start.sh
```

打开 <http://localhost:8000>。首次启动会创建虚拟环境、安装依赖并复制 `.env.example`。

Windows 脚本会依次探测 `python`、`python3`、`py -3`。Conda 环境无法向 `venv` 写入 pip 时，会优先复用当前环境中已安装且可导入的依赖；缺少依赖时再安装到项目隔离目录。

## Docker Compose

```bash
docker compose up -d --build
```

打开 <http://localhost:11451>，或使用 `http://服务器公网IP:11451`。默认绑定 `0.0.0.0:11451`，云服务器还需在安全组／防火墙放行 TCP 11451。数据与自动生成的随机密钥保存在 Docker 命名卷，不读取开发机的 `./data`。首次部署无需创建配置文件。

需要修改端口或配置时，复制 `.env.compose.example` 为 `.env.compose`，使用 `docker compose --env-file .env.compose up -d --build`。主机端口通过 `PUAA_COMPOSE_PORT` 配置，与本地 Python 的 `PUAA_PORT` 分离。仅需宿主机反向代理访问时设 `PUAA_BIND_HOST=127.0.0.1`。HTTP 不加密登录信息，正式使用学校账号前应配置 HTTPS，并在 HTTPS 部署时启用 `PUAA_SECURE_COOKIES=true`。

详细操作、更新与数据保管见 [部署说明](docs/DEPLOYMENT.md)。本轮未在本地构建或运行 Docker。

## 发布与隐私

公开源码不包含个人账户、学校数据、登录会话、通知配置、运行日志、密钥或数据库备份。`.gitignore` 排除整个 `data/` 与本机配置，Docker 构建上下文仅允许应用源码、前端与依赖清单。测试仅使用隔离数据库和模拟响应；设计稿不注入正式程序。

发布前运行 `python scripts/privacy_audit.py --repository .`，检查暂存文件和全部 Git 历史（只报告文件名和风险类型，不输出秘密值）。此检查是发布护栏，不替代人工审查。

## 账户边界

“账户与安全”可设置学校认证刷新间隔，默认 24 小时，可设 1–720 小时。后台每分钟检查是否到期，仅刷新已启用连接所用的直连/WebVPN 认证，不读取作业或签到。计时从该会话最近一次成功认证开始；调整间隔后无需重启。需要已保存学校密码，验证码或认证拒绝时暂停自动登录。数据同步仍使用连接页各自的刷新间隔。

学校会话失效时，已选择记住密码的用户会自动重新认证并重试当前只读查询一次。恢复按用户和直连/WebVPN 隔离，同一会话串行查询，避免并发重复登录。验证码或自动认证拒绝会暂停该会话的自动登录，需手动登录恢复；未保存密码时不尝试自动认证。网络错误不触发重新登录，失败保留旧数据。学校 Cookie 只保存在进程内，重启后按需重新认证；不调用签到提交接口。

- 用户先注册并登录 PUAA；
- 每个用户再单独连接自己的北航统一认证账号；
- 业务查询全部按 `user_id` 隔离；
- PUAA 密码使用 Argon2id；
- 学校密码默认不保存，用户选择自动同步后才使用 AES-256-GCM 加密保存；
- 正式运行路径没有演示适配器或演示数据开关。

## 已接入学校 API

当前只读连接器：

- 本科教务：
- `GET .../api/home/currentUser.do`（会话探活）
- `GET .../student/schoolCalendars.do`
- `GET .../getTermWeeks.do`
- `POST .../student/getMyScheduleDetail.do`
- `GET .../student/exams.do`
- iClass：同步当天与次日，检查点读取课次所在日期；只有唯一匹配且明确 `signStatus=0` 才提醒，`1` 为已签到，其他值不猜测；
- 成绩应用：默认每 15 分钟检查当前学期成绩，首次建立基线，之后在新成绩出现或分数变化时提醒；
- SPOC：作业截止、提交状态和得分，使用 `mrxq` 学期查询代码；
- JUDGE：作业截止、提交状态和得分；开放时间只保留在详情，日历以截止时间归档；
- 博雅：已选课程、签到/签退窗口与状态；
- 阳光体育：使用体育系统自己的学期截止时间；只有剩余次数达到“本周剩余额度 + 后续每周上限”时才进入达标风险提醒；
- 体育场馆：个人预约时间、场地与审批状态；
- 图书馆：个人座位预约时间、地点、座位号与状态。

运行时不依赖 UBAA。UBAA、buaa-api、duaa 只用于交叉核对学校协议，不作为上游服务。每个连接器公开版本、能力、端点与参考源码清单；单一路由失败会单独显示且不会清空旧数据。当前不会代替用户打卡、签到、预约、取消预约或提交作业。

勾选“加密保存”后，后台会自动重建学校会话。每个数据源都可在“连接”页独立设置为手动、5/15/30 分钟、1/6 小时或每天刷新；后台每分钟检查一次到期的数据源。

提醒规则按业务类型显示不同设置：课程可设置上课前提醒，签到可设置下课前检查未签到，图书馆座位/研讨室和场馆预约可分别设置开始前与离开失效前提醒，作业、考试、成绩、阳光体育、博雅和自定义日程也都有各自字段。邮件、WxPusher、Telegram 和自定义 HTTPS Webhook 可多选投递；Webhook 会发送 `title`、`message`、`to` 三个 JSON 字段，本项目没有内置绑定任何短信厂商。
