## 正文和占分

- UBAA `SpocAssignmentDetailRaw` 有 `zynr`，详情 DTO 提供 `contentPlainText` / `contentHtml`。本项目现在保存经过纯文本转换的 `zynr`，不执行 HTML，不自动加载图片。
- UBAA JUDGE 解析器提供整页正文、逐题名称、满分、得分和提交状态。本项目现从已有页面保存整页纯文本及题目表格结构；不能把“已提交”直接推断成满分或 Accepted。
- “占分”需分别定义：作业满分、每题分值、占课程最终成绩比例。前两项有部分已确认来源，第三项尚无可靠字段映射，不可通过满分或各作业分值自行推算。
- SPOC 评分/评语既用于新评分通知，也在共用详情窗口展示；批阅状态未确认时不把列表满分当作个人得分。

## 本轮详情实现与边界

列表保持摘要；待办、今日、日历各视图共用只读详情窗口。基本信息和已知成绩直接展示，评语、正文、题目明细、课程信息分别默认折叠。正文保留换行并独立滚动，学校 HTML 转为纯文本，前端再次转义。未知字段省略或显示“—”，不能用零代替未知。新增字段需下次正常自动/手动同步才会写入旧数据；打开详情不触发学校请求，不修改提交、签到或成绩。附件、成绩占比和逐题评测详情仍未实现，待来源及 URL 核验后扩展。

周日程仍按真实时长排列。小于 74 像素的短卡只显示单行课程名与时间；中等高度增加教师/教室，较高卡再显示状态。卡片子元素禁止被 flex 压缩，完整内容在悬停提示及详情中查看，不把持续时长拉长来容纳文字。
