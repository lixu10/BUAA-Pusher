## 正文和占分

- UBAA `SpocAssignmentDetailRaw` 有 `zynr`，详情 DTO 提供 `contentPlainText` / `contentHtml`。本项目目前没有保存这个详情字段。
- UBAA JUDGE 解析器提供整页正文、逐题名称、满分、得分和提交状态。本项目尚未保存这些结构；不能把“已提交”直接推断成满分或 Accepted。
- “占分”需分别定义：作业满分、每题分值、占课程最终成绩比例。前两项有部分已确认来源，第三项尚无可靠字段映射，不可通过满分或各作业分值自行推算。
- SPOC 评分/评语目前已用于新评分通知，但现有日历详情弹窗只有基本字段，待办也缺少完整详情入口，用户无法直接查看所有已保存信息。

## 建议的下一轮实现（尚未实现）

列表保持摘要；待办、今日、日历共用详情页。分为基本信息、成绩与评语、可展开正文、题目/附件四区。正文保留换行并独立滚动，不直接执行学校 HTML；图片/链接/附件需来源与 URL 校验，外部资源不自动加载。详情不足时使用明确的只读加载动作，不修改提交或成绩。未返回的字段不显示，不能用零代替未知。
