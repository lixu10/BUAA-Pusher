# 独立签到检查与连接模式

## 产品边界

- 课程提醒读取教务课表；签到检查独立读取 iClass，不调用签到提交、定位、扫码或服务器时间接口。
- 每个学校连接分别保存直连 / WebVPN 模式；未上线连接可以预设模式，但仍为 Coming Soon，不能启用。
- 签到默认停用，需要用户主动启用。连接页可独立设置自动同步间隔，0 表示仅手动；新连接建议默认15分钟。旧签到规则保留为待配置，不自动恢复旧规则或重复通知。

## 课次与界面

课程日历继续使用现有课程条目。用标准化课名、准确开始和结束时间唯一关联 iClass 课次，只附加“已签到 / 未签到 / 状态未知”标签。没有匹配记录不等于没有签到要求，更不等于未签到。歧义匹配不猜测。

教务是唯一日历来源。未匹配 iClass 记录只在签到连接详情展示，不生成日历条目。教务独有课程正常显示，不推断未签到。签到规则可排除课程。课程是否结束、是否已签到互不覆盖；签到成功不隐藏课程，也不影响课程提醒或课程变更规则。

界面沿用纸白 #ffffff、背景 #f5f7fa、文字 #172033、次级文字 #6c7a90、边线 #d9e1eb、操作蓝 #145dd7。中文字体沿用 Microsoft YaHei UI / 系统字体。所有字段左对齐；检查点按单行“基准时机 / 分钟 / 删除”排列，移动端换行，不添加解释性段落。

## 检查点

规则配置 1–10 个检查点：课程开始前（最多 10 分钟）、开始后、结束前、结束时。实际检查时间必须在该课次开始前 10 分钟到结束时间（含端点）之间。相同实际时刻合并，过期点不补发。后台每15秒调度，结束检查允许最多30秒执行误差，超过后不补查。

到检查点先看已同步状态。已签到则不请求 iClass，并取消该课程当前规则之后的检查。否则按日期读取只读课程状态，明确返回未签到才发送提醒；查不到课次、未知状态、认证失败均不发送未签到通知。每个检查点只查询一次，多个通知渠道和通知发送重试复用该结果，不额外查询。查询失败不做后台密集重试，下个用户设定的检查点仍可再查。

只在连接的手动/定时同步及规则检查点请求签到状态。同步间隔和提醒检查点分别配置：定时同步更新缓存；检查点先用缓存确认已签到，否则重新查状态。自动同步沿用已保存凭据的后台调度，关闭连接或设为手动即停止周期同步。加载页面、刷新日历、修改规则只读缓存或生成计划，不请求学校。会话按用户与网络模式隔离，缓存只确认同一天同一课次。确认已签到后不因迟到的未签到响应回退。

## 校验与验收

测试覆盖 WebVPN 8346/8347 端口、loginName 重定向、符号转义、0/1/未知状态、多个检查点与渠道、已签到短路、失败不误报、课程合并、歧义匹配、隔离和重启幂等。真实账号只读验收由用户单独同步完成，不自动进行实际签到。
