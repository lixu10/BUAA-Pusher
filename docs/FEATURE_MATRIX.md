2026-10-08 调试范围：仅 SPOC 作业、课程提醒（BYXT 教务课表）、JUDGE 作业开放。课程签到（iClass）及其余业务统一为 `Coming Soon`；不调用任何 iClass 接口，保留代码、数据和配置，暂停同步和提醒，界面及接口禁止启用。下表记录保留实现的能力，开放状态以本段和程序的功能开关为准。

状态说明：

本轮规则扩展（2026-10-08）：课程连接的二级类型为课程提醒、课程变更（含新增）；课程提醒可选上课前或课程结束前的分钟数。SPOC 为截止、新作业、新评分；JUDGE 为截止、新作业。截止提醒支持 1–10 个“天/小时/分钟”提前量。规则设计、基线策略与边界详见 [规则设计](RULES.md)。SPOC 已核实官方脚本的 `pf` / `py` / `pyfs` 与 `zyfs` 含义，并用真实账号只读同步核验现有记录；教师新批阅的通知链使用隔离测试验证，不在真实账号制造评分或测试通知。

- **设计完成**：对象、来源、页面和提醒语义已确定；
- **待样本验证**：已找到协议，但需要真实账户响应确认字段；
- **待接口调研**：尚未确认稳定学校接口；
- **未实现**：正式多用户版本尚未编码。

## 最终范围保证

上表所有条目都属于最终交付范围。开发批次只决定实现顺序，不代表删除或无限期搁置。对于没有稳定学校 API 的功能，必须通过共享来源、ICS、Webhook 或自定义日程提供可用的替代接入，直到原生连接器可用。
