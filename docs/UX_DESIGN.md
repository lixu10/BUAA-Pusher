# PUAA Reminder 交互设计

## 1. 信息架构

```text
未登录
├─ 登录
└─ 注册（由部署策略决定）

已登录
├─ 今日
├─ 日历
│  ├─ 日
│  ├─ 周
│  ├─ 月
│  └─ 日程列表
├─ 待办
├─ 提醒
│  ├─ 规则
│  └─ 发送记录
├─ 连接
│  ├─ 北航账户
│  ├─ 学校连接器
│  └─ 自定义/共享来源
├─ 通知渠道
└─ 账户与安全

管理员
├─ 用户与注册策略
├─ 连接器健康
├─ 共享来源审核
└─ 系统任务
```

“数据源”“规则”“发送记录”不挤在首页。首页只回答今天、风险和连接异常。

## 2. 页面设计

### 2.1 PUAA 登录

- 居中窄表单：用户名/邮箱、密码、登录；
- 注册、忘记密码和部署说明放在次级位置；
- 不出现北航学号字段；
- 登录后才进入北航绑定。

### 2.2 首次引导

三步而非一张设置大表：

1. **连接北航**：选择直连/WebVPN，输入学号密码，处理验证码；
2. **检查数据**：逐项显示教务、iClass、SPOC 等连接结果；
3. **接收提醒**：配置至少一个渠道并发送测试消息。

允许跳过学校绑定，只使用自定义日历。

### 2.3 今日

```text
┌ 日期 / 同步状态                         搜索  新建 ┐
├──────────────────────────────────────────────┤
│ 现在      下一项：软件工程 10:35 · 新主楼 F101 │
├─────────────── 时间轴 ────────────┬──────────┤
│ 08:00  高等数学                    │ 临近截止 │
│ 10:35  软件工程                    │ 作业 2项 │
│ 14:00  博雅课程                    │ 未签到 1 │
├───────────────────────────────────┴──────────┤
│ 全天：图书馆座位观察 · 阳光跑进度              │
└──────────────────────────────────────────────┘
```

没有欢迎语、统计装饰或说明段落。异常以一条可操作提示出现。

### 2.4 周日历

周视图是产品的主界面：

- 横轴为周一至周日；
- 纵轴同时显示节次与真实时间；
- 课程块放在时间网格；
- 截止任务放在对应日期顶部的“截止”轨道；
- 当前时间线贯穿当天；
- 点击空白区域新建事件；
- 点击事件打开右侧详情抽屉，不离开日历。

### 2.5 日视图

窄屏默认视图。包含全天区、时间轴、未定时间待办。支持前后日期滑动，不把周网格缩小到不可读。

### 2.6 月视图

每个日期格最多显示三条关键事项，其余显示数量。考试、截止和连接异常优先于普通课程。点击日期进入日视图。

### 2.7 日程列表

按日期分组，支持来源、类型、状态筛选和搜索。用于查看远期考试、所有作业和同步历史，不代替日历。

### 2.8 事件详情抽屉

只显示真实信息：

- 标题、时间、地点、状态；
- 来源和最后同步时间；
- 学校原始关键信息；
- 当前提醒规则；
- 用户备注和覆盖设置；
- 有写操作时显示单独确认按钮。

### 2.9 提醒规则

采用可读的规则句子，而非暴露 JSON：

```text
如果 [课程签到] 在 [下课前 30 分钟] 仍为 [未签到]
通过 [邮件] 提醒；若 20 分钟后仍未完成，再通过 [短信] 提醒
```

高级编辑器按“范围—时机—条件—重复/升级—渠道”五段展开。

### 2.10 连接

按系统展示健康状态、数据范围、最后成功时间和需要的操作。连接器没有数据时区分：未绑定、没有业务数据、同步失败。

## 3. 视觉方向

### 设计概念

“校园作息纸”：以真实课程时间网格为主角，视觉来自课表、教学周和日历标记，不使用通用 SaaS 仪表盘卡片堆叠。

### 色彩

| Token | 色值 | 用途 |
|---|---|---|
| 北航蓝 | `#145DD7` | 主操作、当前日期、当前时间 |
| 深墨 | `#172033` | 主文字与导航 |
| 雾白 | `#F5F7FA` | 页面底色 |
| 纸白 | `#FFFFFF` | 日历工作面 |
| 线灰 | `#D9E1EB` | 时间网格与分隔 |
| 风险红 | `#C9384B` | 未签到、发送失败 |
| 截止琥珀 | `#A85E00` | 临期任务 |
| 完成绿 | `#18765C` | 已完成、连接健康 |

颜色始终配合文字或图形，不单独表达状态。

### 字体

- 中文：`Noto Sans SC` / `Microsoft YaHei UI`；
- 数字与时间：`Inter`；
- 只用 400、500、650 三档视觉权重；
- 页面标题 28–32px，正文 14px，辅助文字不低于 12px。

### 布局

- 桌面左侧 184px 导航，内容区以日历全宽展开；
- 事件详情使用 360px 右侧抽屉；
- 8px 基础间距，日历网格坚持对齐；
- 卡片只用于独立配置表单，不用于每一条信息；
- 圆角 6–10px，不使用大面积渐变和装饰阴影。

### 图标

统一使用 Lucide。每个操作有可见文字；仅同步、搜索等高频动作允许图标按钮，并提供无障碍名称。

## 4. 响应式

- `>= 1024px`：完整周/月网格和右侧抽屉；
- `768–1023px`：收窄导航，详情覆盖显示；
- `< 768px`：底部导航，日视图默认，周视图横向分页而非整体缩放；
- 触摸目标至少 44px；
- 日历事件支持键盘聚焦和屏幕阅读器时间描述。

## 5. 文案规则

- 使用“今天、日历、待办、提醒、连接”等用户概念；
- 状态必须可行动，如“教务登录已失效 · 重新登录”；
- 空状态给出一个下一步，如“尚未连接北航账户 · 去连接”；
- 不在界面放产品介绍、大段帮助或营销文案；
- 技术路由和原始 JSON 只在诊断模式显示。
